🧮 # Calculadora de Média (Delphi)

Aplicação simples para calcular a média de três notas.

---

✨ ## Funcionalidades

* Cálculo da média
* Resultado automático:

  * Aprovado (≥ 7)
  * Recuperação (≥ 5)
  * Reprovado (< 5)
* Cores no resultado (verde, laranja, vermelho)
* Navegação com Enter (como Tab)
* Entrada apenas de números
* Formatação automática (0,00)
* Limite de notas: 0 a 10

---

🧩 ## Como funciona

1. Digite as três notas
2. Pressione Enter para navegar entre os campos
3. Clique em **Calcular Média**
4. Veja o resultado na tela

---

📌 ## Observações

* O campo é formatado automaticamente ao sair
* Valores inválidos são corrigidos
* Aceita vírgula ou ponto como decimal
